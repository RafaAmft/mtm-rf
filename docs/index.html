Como o cálculo funciona

A LTN paga R$ 1.000 no vencimento e nada antes. O preço hoje (PU) é esse valor trazido a valor presente:

PU = 1000 / (1 + taxa)dias úteis / 252

  • Na curva: usa a taxa da compra. O valor cresce de forma suave até R$ 1.000.
  • A mercado (MtM): usa a taxa de hoje. Mostra quanto a carteira valeria se vendesse agora.
  • Ágio/Deságio: diferença entre os dois. Juros subiram → deságio; caíram → ágio.
  • DV01: quanto a carteira perde se a taxa subir 0,01 ponto percentual.
